MAHESH PORTFOLIO
================

Files:
- index.html        Main portfolio page
- styles.css        Responsive styling and visual design
- script.js         Mobile navigation and scroll animations
- Mahesh_Resume.pdf Resume download

To run locally:
1. Keep all files in the same folder.
2. Open index.html in a browser.

To deploy on GitHub Pages:
1. Create a repository.
2. Upload all files from this folder.
3. In GitHub, open Settings > Pages and choose the main branch/root folder.

Profile photo:
- A professional placeholder is included in the hero section.
- Later, replace the placeholder inside .photo-placeholder in index.html with your image.
