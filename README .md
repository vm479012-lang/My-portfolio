2. Open `index.html` in a modern web browser.
3. Keep the supporting files and `Mahesh_Resume.pdf` in the same project folder when using the multi-file version.

## 🌐 Deployment

This portfolio can be deployed using **GitHub Pages** or **Vercel**.

### GitHub Pages

1. Create a GitHub repository.
2. Upload the portfolio files.
3. Open **Settings → Pages**.
4. Select the deployment branch/folder.
5. Save and open the generated GitHub Pages URL.

### Vercel

1. Import the GitHub repository into Vercel.
2. Use the project root as the deployment directory.
3. Deploy the site.
